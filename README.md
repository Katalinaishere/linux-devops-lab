# Linux & DevOps Lab

Hands-on Linux administration and DevOps practice using Ubuntu on WSL2.

## Projects

- **Bash:** Backup automation, system information, and project checks.
- **System Administration:** Health monitoring, logging, and cron scheduling.
- **Filesystem:** File operations and management.
- **Networking:** Network diagnostics.
- **DevOps:** Automation and deployment scripts.
- **Permissions:** Linux file permissions.

## Tech Stack

Bash · Linux · Ubuntu · Git · Cron · WSL2

## Goals

Build practical skills in Linux administration, scripting, automation, troubleshooting, and DevOps.
